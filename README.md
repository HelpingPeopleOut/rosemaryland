# RoseMaryLand

Premium Next.js site for RoseMaryLand botanical care — rose water, rosemary water, Gua Sha tools, gift cards, and haircare appointments in Pasadena & Victorville, CA.

## Stack

- Next.js (App Router) with static export
- TypeScript + Tailwind CSS v4
- Glass / frost UI, advanced order form, accordions

## Develop

```bash
npm install
npm run dev
```

## Build (static)

```bash
npm run build
```

Output lands in `out/` for Cloudflare Pages or any static host.

## Forms

Orders and newsletter submissions post to FormSubmit (`workorders@hpo.center`, CC `support@rosemaryland.love`), same as the previous site.
